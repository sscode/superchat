# Support

Superchat is an early open-source beta maintained on a best-effort basis.

- Search existing GitHub issues before opening a new one.
- Use the bug report form for reproducible defects.
- Use the feature request form for product ideas.
- Include the Superchat version, macOS version, connection type, and concise
  reproduction steps.
- In Settings, use **Export diagnostics** when maintainers request it. Inspect
  the JSON before attaching it; the exporter omits chats, drafts, file paths,
  MCP commands, and credentials by design.
- Do not include API keys, provider tokens, private prompts, chat databases, or
  sensitive attachments.

Security vulnerabilities and sensitive privacy concerns must be reported
privately as described in `SECURITY.md`.

Questions about OpenRouter, Codex, ChatGPT subscriptions, macOS, or configured
MCP servers may need to be handled by the corresponding provider.
