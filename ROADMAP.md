# Roadmap

Superchat's near-term focus is a dependable local-first macOS chat workspace.

## Current priorities

- Improve Codex integration using the documented local App Server interface.
- Strengthen attachment, import, export, and backup workflows.
- Expand MCP support while preserving explicit user approval for tool calls.
- Improve accessibility, keyboard navigation, and small-window layouts.
- Make releases easier to verify with checksums and build provenance.

## Later

- Optional, end-to-end-encrypted sync that is not required for local use.
- Additional provider connections using supported API authentication.
- More platforms after the macOS experience and packaging are stable.

## Non-goals for the current release

- A Superchat-hosted model proxy.
- Autonomous MCP tool loops without user review.
- Routing consumer subscription credentials through unsupported third-party
  authentication flows.

The roadmap describes direction, not a commitment to dates or specific
features. Issues and pull requests should stay focused on the current scope.
